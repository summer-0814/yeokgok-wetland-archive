# 역곡습지 생태공원 조성을 위한 민관거버넌스 협의과정 아카이브

부천 역곡공공주택지구 개발 과정에서 시민이 발견한 맹꽁이 서식 습지(역곡습지)를 생태공원(생추어리)으로 지키기 위해 2024년부터 2026년 11월까지 시민사회·부천시·LH·시공사가 나눈 협의와 활동을 정리한 공개 기록입니다.

- 웹페이지: `index.html` (기록), `purpose.html` (의의와 목적: 계층적 완화, 국립생태원 대체서식지 전수조사, 근거의 강도). GitHub Pages로 바로 게시 가능한 정적 사이트이며 빌드 과정이 없습니다.
- 원자료: 부천시지속가능발전협의회 「역곡습지 관련 협의과정」(2026. 11. 9.)과 공문·발표자료·워크숍 자료
- 협업: 도시숲시민모임, 산울림청소년센터, 생명다양성재단

## 데이터

| 파일 | 내용 | 형식 |
|---|---|---|
| `data/timeline.json`, `data/timeline.csv` | 협의·활동 기록 (날짜, 분류, 제목, 세부내용, 사진 경로, 출처) | JSON / CSV(UTF-8 BOM) |
| `data/letters.json`, `data/letters.csv` | 공문 8건 본문 (날짜, 발신, 수신, 문서번호, 제목, 본문) | JSON / CSV |
| `data/vegetation.json`, `data/vegetation.csv` | 역곡습지 식생조사 4회(2025. 7. 22., 7. 30., 8. 31., 2026. 7. 29.) 종 목록. `1` = 확인, 그 외 문자열 = 조사자 메모 | JSON / CSV |
| `data/complaints.csv` | 관련 국민신문고 민원 목록 (신청번호, 제목, 신청일, 처리기관) | CSV |
| `data/articles.csv` | 언론보도 목록 (매체, 제목, URL) | CSV |
| `img/` | 현장 사진, 지도, 발표자료, 2003년 자료 일부 | JPEG |

`timeline.json` 항목 구조:

```json
{"id":"e11","date":"2025-12-02","date_label":"2025. 12. 2.","category":"공문·민원·답변",
 "title":"...","details":["..."],"links":[{"title":"...","url":"..."}],
 "images":[{"file":"img/image46.jpg","caption":"..."}],"key":true,"source":"..."}
```

- `date`는 정렬용 ISO 날짜입니다. 원문에 월까지만 있는 기록은 그 달의 임의 날짜로 두었으니 `date_label`(원문 표기)을 기준으로 보세요.
- `category`: 간담회·협의 / 공문·민원·답변 / 모니터링·현장활동 / 행사·교육·홍보 / 공사·현장 대응
- `key`: 협의 방향이 바뀐 주요 기록

## 관점과 한계

기록 대부분은 부천시지속가능발전협의회와 도시숲시민모임 등 시민사회 쪽 자료입니다. LH와 부천시의 입장은 해당 기관의 공문과 국민신문고 답변을 출처(`source` 필드)로 달았고, 간담회 내용은 부천지속협이 작성한 회의 기록입니다. 날짜는 부천지속협 「역곡습지 관련 협의과정」(2026. 11. 9.) 원문을 기준으로 했습니다. 이 기록은 유엔 지속가능발전목표(SDGs) 4.7, 11.7, 15.5, 16.7과 관련됩니다.

## 개인정보 처리

공개 데이터로 쓰기 위해 다음을 적용했습니다.

- 사람 이름은 모두 성만 남기고 가렸습니다 (예: 이○○ 팀장). 기관명과 직함은 그대로 두었습니다.
- 개인 휴대전화, 후원 계좌, 공문 결재란의 담당자 이름·이메일, 서명은 빼거나 잘라내거나 흐리게 처리했습니다.
- 메신저·민원 앱 화면 캡처, 워크숍 참석 명단, 어린이 얼굴이 가까이 나온 사진은 싣지 않았습니다.
- 강연자 발표자료와 외부 보고서는 요약과 출처만 적었습니다.

## 이용 조건

- 텍스트와 데이터(`data/`): 크리에이티브 커먼즈 저작자표시 4.0 국제(CC BY 4.0) — 출처를 「부천시지속가능발전협의회, 역곡습지 협의과정 아카이브」로 표시하면 자유롭게 이용할 수 있습니다.
- 사진·포스터·발표자료 이미지(`img/`): 공식 회의와 활동을 기록한 사진으로, 촬영자의 공개 동의를 전제로 싣습니다. 저작권은 각 촬영자와 작성 단체(부천시지속가능발전협의회, 도시숲시민모임, 생명다양성재단 등)에 있으며, 출처를 밝히면 비영리 기록·교육 목적으로 이용할 수 있습니다.
- 사진에 나온 분이 게시를 원하지 않거나 촬영자가 이의를 제기하면 해당 사진을 내립니다. 아래 정정 요청 경로로 알려 주세요.
- 공문 본문은 공공기관·단체가 작성한 문서를 옮긴 것입니다.
